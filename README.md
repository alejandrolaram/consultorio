# Sistema de administración de citas clínicas

Este programa simula un sistema de gestión para un consultorio clínico, permitiendo administrar accesos, dar de alta doctores, pacientes y agendar citas médicas con persistencia de datos.

## Instalación y Configuración
1. Asegúrate de tener instalado el **JDK 11** o superior.
2. Clona este repositorio en tu máquina local usando el comando de Git correspondiente.
3. Abre el proyecto desde **IntelliJ IDEA**.
4. Construye el archivo ejecutable utilizando la configuración para generar el **FAT JAR**.

## Uso del Programa
Para ejecutar la aplicación portable, corre el siguiente comando en su terminal:

```bash
java -jar consultorio.jar
```
